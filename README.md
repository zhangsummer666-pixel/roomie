# 合租生活管家 · Roomie

一个为合租年轻人设计的轻量生活管理工具，解决「房租水电分摊不清、清洁值日混乱、公共物品消耗无记录」等常见矛盾。

## 功能模块

| 模块 | 说明 |
|------|------|
| 💸 费用 AA | 记账、均摊/按比例/自定义金额分摊、一键结算（自动简化债务：谁该给谁多少钱） |
| 🧹 值日排班 | 家务项目登记、按频率自动轮换负责人、完成打卡、值日积分榜 |
| 🧻 公共物品 | 库存登记、低库存提醒、补货记录（谁采购） |
| 📜 室友公约 | 共同约定管理、室友「同意」表态与达成度统计 |
| 👥 室友 | 成员管理、个人垫付与净结余一览、数据导出/导入备份 |

## 技术特点

- 纯前端单文件应用（HTML + CSS + 原生 JS），**无任何外部依赖**，可直接部署到任意静态托管
- 数据用浏览器 `localStorage` 持久化，无需登录、无需后端
- 响应式设计，桌面端 + 移动端均可使用
- 内置示例数据，首次打开即可体验完整流程

## 本地运行

直接双击 `index.html` 打开，或：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```
